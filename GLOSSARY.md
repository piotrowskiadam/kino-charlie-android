# Domain glossary

- Film: a title with stable Charlie source ID, source metadata and poster.
- Seans / screening: a film shown at one date and time in a room, with an optional exact checkout URL.
- Repertuar / schedule day: a validated snapshot of all screenings published for one date.
- Saved film: a local bookmark of a film, independent of ticket purchase.
- Synchronization: refresh of published schedule days and supporting film assets, preserving prior data on failure.

**App release / wydanie aplikacji**:
A published version of Charlie · repertuar that users can install as an update. This is distinct from a film release or a newly published schedule.
_Avoid_: premiere, repertoire refresh.
